# ✈️ Airline Analytics Dashboard – Power BI

## 📊 Project Overview

The Airline Analytics Dashboard is an interactive Power BI dashboard designed to analyze airline performance, revenue, profitability, operating costs, passenger satisfaction, flight delays, and route performance.

The project transforms airline data into meaningful visual insights that can help understand business performance and operational efficiency.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze total flights and passengers
- Analyze airline revenue and profitability
- Calculate total profit
- Analyze fuel and maintenance costs
- Monitor flight delays and on-time performance
- Analyze passenger satisfaction
- Compare airline performance
- Analyze ticket classes
- Analyze flight routes
- Create interactive business intelligence dashboards

## 📈 Dashboard Features

### 1. Revenue & Profitability Analysis

Analyzes revenue and profit across different airlines to understand financial performance.

### 2. Maintenance Cost Analysis

Compares maintenance costs between airlines.

### 3. Fuel Cost Analysis

Shows fuel costs by airline and helps identify differences in operating expenses.

### 4. Flight Delay Analysis

Analyzes flights according to delay categories such as:

- On Time
- Moderate Delay
- Heavy Delay

### 5. Passenger Satisfaction

Analyzes passenger satisfaction across different ticket classes.

### 6. Route Analysis

Provides insights into flight routes and the number of flights operating on different routes.

### 7. Interactive Filters

Users can filter the dashboard using:

- Airline
- Airport
- Aircraft Type
- Ticket Class
- Date
